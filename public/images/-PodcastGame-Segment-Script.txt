Scenario 1 – External Monitoring
Host:

(Let them answer anything.)

“Pwede yang idea mo! Relating to our topic, this is External Monitoring—binabantayan natin ang mga threats sa labas ng organization or business.
We use tools like:

CERT alerts (Computer Emergency Response Team alerts)
Security vendor bulletins
Public threat feeds or news

Analogy: Para itong malaking gate sa labas ng bahay mo bago makapasok ang magnanakaw.”

Host:
“Nagbabantay ka ng proxy server, makikita mo doon kung ano ang mga bawal ma-access na website. Nakita mo may nag-request ng HTTP. Chinheck mo ang IP address—printer pala! Weird, di ba? Ano gagawin mo?”
(Let them react.)
Host (Explain):
“Isa itong dahilan kung bakit mahalaga ang Internal Monitoring.

Alam mo kung ano ang devices sa network.
Gumagamit tayo ng IDPS (Intrusion Detection and Prevention System) para ma-block ang attack.
Difference Analysis compares current state vs baseline para makita ang changes.

Analogy: Para itong CCTV sa bahay mo—kapag may gumalaw na kakaiba, alam mong may ibang tao.”

✅ Digital Forensics Segment
Host:
“Kung gusto nyo maging detective, magugustuhan nyo ito!
Scenario: May data breach. Paano malalaman ang nangyari? Nakita mo na may nag-bypass sa network at dinelete lahat ng traces. Paano mo malalaman?”

Steps in Digital Forensics (with explanation for beginners)
1. Identify – Alin ang system na inatake

Goal: Hanapin kung anong computer, server, o device ang na-compromise.
How: Check logs from firewalls, proxies, and servers. Look for unusual IP addresses or failed logins. Use monitoring tools like SIEM (Splunk).


2. Acquire Evidence – Kopyahin nang hindi binabago

Goal: Gumawa ng exact copy ng data nang hindi naa-alter ang original.
How: Use disk imaging tools (FTK Imager, EnCase) and memory dumps. Always use write blockers para hindi mabago ang original data.


3. Authenticate – Siguraduhin na tama at original ang ebidensya

Goal: Patunayan na hindi na-tamper ang evidence.
How: Generate hash values (MD5, SHA-256) for original and copy. If they match, authentic ang copy.


4. Analyze – Hanapin ang clues

Goal: Alamin kung ano ang nangyari.
How: Use forensic tools (Autopsy, X-Ways) to check files, logs, and deleted data. Look for malware, suspicious scripts, or unauthorized access. Reconstruct timeline.


5. Report Findings – Gumawa ng report para ma-improve ang process

Goal: I-detalye ang nangyari para sa management o legal team.
How: Include what happened, how it happened, affected data, screenshots, logs, and hash verification. Suggest security improvements.


Extra:
Kung aabot sa korte, kailangan ng Chain of Custody—record kung sino humawak ng evidence at kailan, para valid ito.
